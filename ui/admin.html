Reports

Reports answer how the billing company and each client are doing. Every KPI has a definition (RP-07), every chart has a table view, and client reports export as PDFs branded with the billing company, not Cleanpost.

RP-01

Reports overview

PageMVPRoute /reports
Purpose
Show how every client is doing in one place so an owner can see where to spend attention.
Data
Materialized report tables (reports.rollup job, hourly) over claims, claim_events, remittances, work_items for clients in the user's scope and the selected period. Comparison to the previous period of equal length.
Actions
  • Date range picker (presets: this month, last month, last 90 days, custom).
  • Info icon on each KPI opens RP-07.
  • Chart/Table toggle on each chart.
  • Row click opens RP-02 for that client.
  • Export opens RP-06.
States
Loading: KPI and chart skeletons. No claims in range: empty state "No claims in this period" with a link to change the range. Data older than 2 hours: "Updated 3:00 pm" caption turns warning.
Rules
Billers see only their assigned clients. Figures never link directly to patient lists from the overview; drill-down goes through the client report. Deltas use green only when the direction is good for the business.

S-07
