Cleanpost UI reference

170 designs for the Cleanpost app, its emails and PDFs, and the marketing website. Each design sits beside its spec: purpose, data, actions, states and rules. IDs match the Cleanpost View Inventory. All patient and practice data is synthetic.

Built from the Cleanpost Design System tokens (assets/tokens.css) and one component stylesheet (assets/components.css). Use the Theme button to check dark mode.
