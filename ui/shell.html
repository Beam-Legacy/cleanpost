Shell and system states

The frame every screen sits in, the global tools reachable from anywhere, and the shared patterns for loading, empty, error, no-access and offline states. Pages reuse these instead of designing their own.

G-01

App shell

Page frameMVP
Purpose
Hold every app page: sidebar navigation, top bar with client switcher, search, help, notifications and user menu, and the content area.
Data
Session user (name, initials, role, tenant); work item count assigned to the user; open manual task count; unread notification count; current client filter.
Actions
  • Nav items route to their area; active item uses aria-current.
  • Collapse toggle (or [ key) shrinks the sidebar to 64px icons with tooltips.
  • Client switcher (G-02), search (G-03, ⌘K), help (G-07), notifications (G-04), avatar (G-05).
States
Billers do not see the Admin section. Collapsed state remembered per user. Platform banner (G-13) sits above the top bar when active. Below 1024px the sidebar starts collapsed.
Rules
Content max width 1440px with space-6 padding. Top bar 56px. The client filter is always visible in the top bar and applies to every page.

Purpose
Filter every screen to one client or all clients in the user's scope.
Data

Actions

Rules

G-03

Global search and command palette

ModalMVP⌘K or /
Purpose
Find any patient, claim, remittance or client, and run common commands, without leaving the keyboard.
Data
Search across patients (name, DOB), claims (patient control number, payer claim number), remittances (trace number), clients; command list filtered by role.
Actions
Type to search (debounced 150ms); ↑↓ move; Enter opens; Tab cycles groups; Esc closes. Commands start with ">" or match by name.
States
Empty query: recent records and suggested commands. No results: "Nothing matches 'x'" with tip to search by control or trace number. Loading: skeleton rows under each group.
Rules
Results respect client scope. Every search query is audit-logged (query hash and result count, not the text if it looks like a name). Patient rows show "Last, F." and age; full DOB only on match by DOB.

G-08

Toast

ComponentMVP
Purpose
Confirm an action in a few words, offer Undo where it is safe, and report background errors.
Data
Message, optional action (Undo, Retry, View), severity.
Actions
Undo reverts within 10 seconds; Retry re-runs the failed request; View opens the record. Close dismisses.
States
Confirmation (ink), error (danger, stays until dismissed). Up to 3 stacked, bottom left, newest on top.
Rules
No Undo for actions that already sent data to a payer or a PM; those confirm beforehand (G-11). Toasts are announced through a polite live region; errors use assertive.

G-09

ModalMVP
Purpose
Warn before signing the user out after 15 minutes idle.
Data

G-11

Confirm action

ModalMVP
Purpose
Pattern for actions that cannot be undone: sending data to a payer, writing to a PM, deleting or voiding.
Data
What will happen, to how many records, where it goes, and the amount.
Actions
Primary names the outcome ("Send 6 claims", "Void claim"); Cancel. Destructive variants require typing or checking a confirmation when more than one record is affected.
States
Sending: button shows progress and the modal can't be closed until the request returns. Partial failure: lists what failed with Retry.
Rules
Default focus on Cancel for destructive actions, on the primary for routine sends. Every confirmation is audit-logged with the actor.

System states

Shared patterns for loading, empty, error, no access, not found and offline. Every page uses these in place of its own; page specs only describe the copy that changes.

G-20

Loading

StateMVP
Purpose
Show the shape of the page while data loads so nothing jumps when it arrives.
Data
None; skeleton matches the layout: table, detail page, dashboard.
Actions
None. Page chrome (sidebar, top bar, page title, filters) renders immediately and stays usable.
States
Skeleton appears after 200ms (avoid flicker). After 10 seconds, show "Still loading…" under the title; after 30, switch to G-22.
Rules
No full-page spinners. Shimmer stops under prefers-reduced-motion. aria-busy on the region.

G-21

Empty

StateMVP
Purpose
Say what will appear here and what to do next, so an empty area never looks broken.
Data
Page-specific copy: title, one sentence, primary action.
Actions
One primary next step (e.g. Add client, Upload 835); optional secondary link to help.
States
"Nothing yet" (cobalt glyph: the feature hasn't been used), "All done" (green glyph: work cleared), "No matches" (neutral, inline in tables with Clear filters).
Rules
Copy names the specific thing, never "No data".

G-25

Offline or reconnecting

ComponentMVP
Purpose
Tell the user the connection dropped and that their work is safe.
Data
Connection state; count of edits waiting to save.
Actions
Retry now. Actions that send data (release, post, resolve) are disabled while offline with a tooltip.
States
Reconnecting (warn), Offline after 30 seconds (bad), Back online (good, auto-hides after 3 seconds).
Rules
Pinned under the top bar. Nothing is sent to a payer or PM from a queued offline action without the user confirming once back online.
